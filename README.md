# Monte Carlo Methods in Physics

A computational laboratory exploring stochastic algorithms, random sampling, and probabilistic simulations in statistical mechanics and quantum physics.


## Modules & Architecture

| Module | Focus Area & Numerical Schemes | Primary Scope |
| :--- | :--- | :--- |
| **`random-walks/`** | 1D/2D/3D random walk models and diffusion dynamics | Stochastic processes & transport theory |
| **`integration/`** | Hit-or-miss and importance sampling methods | High-dimensional numerical integration |
| **`markov-chain-mc/`** | Metropolis-Hastings algorithms and detailed balance | Markov Chain Monte Carlo (MCMC) sampling |
| **`lattice-models/`** | 2D Ising model phase transitions and ferromagnetism | Spin systems & critical phenomena |
| **`applications/`** | Variational Monte Carlo (VMC) and ensemble averages | Quantum states & statistical mechanics |


## Tech Stack

* **Language:** Python 3.x
* **Core Libraries:** `NumPy`, `SciPy`, `Matplotlib`
